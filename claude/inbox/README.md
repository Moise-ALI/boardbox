# Inbox — brouillons

Dépose ici une idée en vrac (`ma-feature.md`) : liste, texte libre, captures, peu importe.
Puis lance `/kit:feature ma-feature` : la fiche propre est créée dans `claude/features/` et les questions manquantes te sont posées.
Supprime le brouillon une fois la fiche validée.

Ce qui aide dans un brouillon : **qui** a le besoin et **pourquoi**, le **comportement attendu**, les **cas limites** connus, les **contraintes** (droits, volumes, compatibilité).
